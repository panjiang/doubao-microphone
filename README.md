# 豆包远程

用手机作为无线麦克风，远程控制电脑上的豆包输入法完成语音输入。把光标放在电脑输入框里，在手机上按住说话，文字就会输入到电脑上。

## 下载与安装

从发布页下载对应平台的文件。电脑需要安装并启用豆包输入法。[下载 v0.2.7](https://github.com/panjiang/doubao-remote/releases/tag/v0.2.7)

| 平台 | 安装方式 |
| --- | --- |
| Windows 11 x64 | 运行 `.exe` 安装包。安装器会准备 VB-CABLE。Windows 语音触发对豆包输入法的版本和设置有要求，详见安装指南。 |
| macOS 14.2+（Apple Silicon） | 打开 `.dmg` 运行安装器，按提示准备 BlackHole 2ch，并在系统设置中授权辅助功能。 |
| Android 10+ | 安装 APK，按手机提示允许安装并授予麦克风权限。 |
| iPhone（iOS 18+） | 可以直接使用 Safari。原生 App 的真机包需要自行签名后安装。 |

## 首次配置

1. **连接网络。** 手机和电脑连到同一路由器。电脑可以用网线。
2. **设置麦克风。** Windows 在豆包输入法中选择 `CABLE Output`，在豆包远程中选择 `CABLE Input`。macOS 两边均选择 `BlackHole 2ch`。
3. **扫描二维码。** 从电脑托盘或菜单栏打开配置页，点击「生成配对二维码」，用豆包远程 App 或手机相机扫描。使用 Safari 时，首次按页面提示安装并信任本机证书。

[查看详细安装与首次配置指南](docs/getting-started.md)

## 按住说话

1. 把电脑光标放在要输入文字的地方。
2. 在手机页面顶栏以下按住并说话。
3. **在圆内松手**会完成听写，并默认等 1 秒按 Enter。**滑出圆外松手**只完成听写。滑回圆内后松手可恢复回车。

Enter 会发送消息还是换行，由电脑上当前的应用决定。可在配置页调整回车等待时间。等待期间再次按住，会取消上一轮待发的 Enter。

使用时让手机停留在输入页面。锁屏、切到后台或断线会结束本次输入，返回后重新按住即可。麦克风在松手传完尾音后关闭，默认不保存录音或识别正文。

遇到连接、配对或语音输入问题，请查看[故障排查与卸载](docs/troubleshooting.md)。
