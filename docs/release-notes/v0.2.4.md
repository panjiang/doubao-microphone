用手机作为电脑的无线麦克风和按住说话遥控器，由电脑端豆包输入法识别并写入当前输入框。

本次修复连接中断后的恢复行为：

- 网络断开、状态发送积压或音频设备异常时，只结束当前会话并清理声音、快捷键和待发 Enter，不再误设为全局暂停。网络恢复后，再次按住即可重新连接；电脑 IP 改变仍需更新地址并重新扫码。
- 同一已配对手机重新连接会替换自己的旧连接，旧连接的迟到消息不会影响新会话；另一部手机不会抢占仍有效的连接。
- 输入代理的请求与回复按编号匹配，超时后不复用旧通道，修复迟到回复被误当作 Enter 结果的问题。
- 输入服务故障后先确认旧进程退出和按键释放，再有限重建。最多连续三次，间隔约 0.5、1、2 秒；健康运行 30 秒后重置额度，持续失败则提示检查权限或重启。
- 手动暂停与故障状态分开显示，自动恢复不覆盖用户暂停。恢复不续播旧录音、不重新按下旧快捷键、不补发旧 Enter。
- 手机网页新增电脑响应超时检测；现有 iPhone / Android App 与配对信息继续兼容，无需为本次桌面修复重装手机 App。
