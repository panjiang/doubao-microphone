# 安装与首次配置

本指南适用于豆包麦克风首版 0.1.0。iPhone 和 Android 的构建号均为 1。

Android 10+ 原生 APK 的安装与配对见 [Android 说明](../android/README.md)；电脑环境和虚拟音频配置仍使用本指南。

从 [GitHub Releases](https://github.com/panjiang/doubao-microphone/releases) 下载首版内部试用安装包，也可以[从源码构建](development.md)。安装前请退出旧版，避免占用同一端口。豆包麦克风会创建独立的配置、证书和配对记录，首次使用请重新扫码。iOS 真机产物需要自行开发签名。

## 准备电脑

先安装并启用[豆包输入法](https://ime.doubao.com/pc)。本项目不包含豆包输入法，也不自行识别语音。

### Windows

- 系统要求：Windows 11 x64。
- 下载 `DoubaoMicrophone-0.1.0-windows-x64.exe`，在同一页确认许可和试用证书信任，点击「安装」，完成一次管理员授权。安装器准备 UMDF 虚拟键盘，并在缺少音频设备时一并安装官方 VB-CABLE；结束后按提示重启。
- 在豆包中把录音设备明确设为 **CABLE Output**；本程序输出选择 **CABLE Input**。
- 默认从桌面快捷方式启动，也可在托盘菜单中打开配置页。

- 在豆包输入法中开启「语音快捷键」，将长按键设为 **右 Alt**。豆包麦克风配置页应显示「固定：右 Alt（UMDF）」。
- 试用驱动使用 100 年自签名证书，安装页会显示证书指纹和信任范围。组件访问失败时，配置页会提示具体问题。

驱动、证书和卸载说明见 [Windows 安装指南](windows-installer.md#umdf-受控试用包)。

### macOS

- 系统基线：macOS 14.2+；已验证 Apple Silicon，Intel 尚未实机验证。
- 双击构建出的 `.pkg`，按系统提示完成安装。缺少虚拟麦克风时，安装过程会自动准备；已有设备会复用。无需重启时应用会尝试自动打开；系统要求重启时，重启后从“应用程序”打开豆包麦克风。
- 如系统提示重启，请重启。在豆包和本程序中均选择 **BlackHole 2ch**。
- 首次启动缺少权限时，应用会自动打开「系统设置 → 隐私与安全性 → 辅助功能」，开启“豆包麦克风”即可；已经授权时不会再次打开。若系统未列出应用，手动添加：

  ```text
  /Applications/豆包麦克风.app
  ```

- 豆包麦克风固定使用 **Fn / 地球仪**。在豆包中将长按快捷键设为 Fn，并切换到豆包输入法，或在豆包中启用全局语音。

现有 Mac 产物使用开发签名，尚未完成 Developer ID 公证。正式发行条件与具体实测范围见 [macOS 验证记录](macos-validation.md)。

## 检查配置

从托盘或菜单栏打开首页。左侧检查电脑，右侧显示配对二维码；运行状态和暂停操作位于顶部。通过右上角「设置」进入独立页面，左侧分为常规、设备管理、高级与诊断、帮助。常规只展示电脑名称、自启动、网络、音频设备和触发方式；仅有一个可用网络或音频设备时直接显示结果，需要时再调整：

1. **运行环境**：查看虚拟麦克风、豆包安装及运行、豆包麦克风、长按键和语音开关的结果。Mac 还会检查当前输入法及辅助功能权限。
2. **音频与网络**：选择对应虚拟设备；网络默认采用“自动选择”，每次启动优先选择可用的有线网络。手动选择网卡时只保存网卡名称，每次启动读取它的当前 IP。只有一张可用网卡时直接显示“自动选择（网卡名）”，有多张可用网卡时才显示下拉选择；自动选择会一直保留自动模式；电脑和手机不必都用 Wi-Fi。
3. **保存设置**：修改后底部出现“放弃修改”和“保存并返回”。切换分类会保留修改，离开设置页时会提醒；需要重启时保存后留在设置页提示。IP 或端口变化后退出、重开程序，再重新扫码。

「重新检测」检查已保存的配置，不会覆盖表单中尚未保存的输入。黄色“无法确认”表示字段、权限或设备状态不足以得出结论；请按结果说明核对，不能视为通过。

默认启用登录自启动，可在配置页关闭。

## 配对 iPhone

### 使用豆包麦克风 App

1. 按 [iOS 构建与安装说明](../ios/README.md)把 App 安装到 iPhone；当前没有 App Store 或 TestFlight 安装入口。
2. 打开电脑首页，二维码会自动显示；过期后点击「刷新二维码」。同一标签页往返设置不会更换未过期二维码。
3. 打开「豆包麦克风」并扫码，配对成功后电脑二维码自动收起。

App 使用二维码内的证书建立本台电脑的专用信任，不需要安装系统证书。顶部“已配对”表示凭据已保存；实际声音连接在按住时自动建立。

首页显示当前连接设备和已配对数量；通过「管理设备」进入设置页，完整设备列表会显示名称和短配对编号，例如 `iPhone · A7C2D8F1`。可点击“改名”设置为“工作手机”等容易辨认的名称，已有配对也能修改，改名不会改变配对凭据。列表中的“当前连接”标记可帮助确认正在使用哪台手机；短编号对应配对记录，重新配对后会生成新编号。

### 使用 Safari 网页

用手机相机扫描**同一个二维码**进入向导，然后：

1. 用 Safari 下载并安装本机证书描述文件。
2. 在「设置 → 通用 → 关于本机 → 证书信任设置」开启配对向导所列本机 CA 的完全信任。
3. 返回向导，打开 HTTPS 输入页完成配对。

安装描述文件与开启信任是两个步骤，缺一不可。二维码五分钟内单次有效，流程中若过期，请在电脑重新生成。选择 App 时无需执行这组证书步骤。

## 开始说话

电脑光标放在目标输入框：

iPhone App、Android App 和网页都在顶栏以下任意位置按住说话，按下位置出现直径 180 的固定圆。圆内松手会在听写结束后延迟按 Enter；任意方向滑出圆外松手只完成听写。滑入顶栏后松手也只完成听写。

滑回操作区域后松手可恢复 Enter。回车默认等待 1000ms，可设为 0–5000ms；具体发送消息还是换行由当前电脑应用决定。等待期间再次按住、断线或暂停接收会取消待发回车；前台目标变化或修饰键仍按住时也会跳过。

首次使用请允许麦克风及局域网访问，若已松手或被权限窗口中断，完成授权后重新按住。正常松手传完尾音后关闭麦克风，连接和心跳保留；再次按住自动启动麦克风。App 前台保持亮屏，网页请求浏览器 Wake Lock；浏览器不支持或系统拒绝时，请手动保持亮屏。切后台、锁屏、来电或网络中断会结束本次输入。

## 连接与权限问题

- 电脑可接网线，手机使用同一路由器下可互相访问的 Wi-Fi；访客隔离、VPN 或虚拟网卡可能影响地址选择。
- macOS 若提示接收入站连接，允许本应用；Windows 只需为本程序放行所用私人网络。
- 默认手机端口为 TCP `38441`（首次向导）和 `38443`（HTTPS/WSS）。管理页的 `127.0.0.1:38440` 只在电脑本机使用，不能发给手机。
- 不需要开启虚拟设备的“侦听”，也不需要把声音播放到扬声器。

仍有问题时查看[故障排查](troubleshooting.md)。
