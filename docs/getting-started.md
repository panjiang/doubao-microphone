# 安装与首次配置

本指南适用于桌面端 0.2.6、iPhone App 0.1.0（构建 32）和 Android App 0.1.9（构建 10）。

Android 10+ 原生 APK 的安装与配对见 [Android 说明](../android/README.md)；电脑环境和虚拟音频配置仍使用本指南。

可从 [v0.2.6 Release](https://github.com/panjiang/doubao-remote/releases/tag/v0.2.6) 获取开发预览产物，也可以[从源码构建](development.md)。iOS 真机产物仍需自行签名；下文安装步骤不代表已经完成面向所有用户的正式分发。

## 准备电脑

先安装并启用[豆包输入法](https://ime.doubao.com/pc)。本项目不包含豆包输入法，也不自行识别语音。

### Windows

- 系统要求：Windows 11 x64。
- 完整安装器在缺少音频设备时自动准备官方 VB-CABLE，按系统提示完成管理员授权及重启。
- 在豆包中把录音设备明确设为 **CABLE Output**；本程序输出选择 **CABLE Input**。
- 默认从桌面快捷方式启动，也可在托盘菜单中打开配置页。

**语音触发是当前 Windows 版的重要限制：**

- 已有可访问的 UMDF 组件时，程序使用右 Alt。该组件仍属于研究实现，普通安装包不包含它，尚未完成正式安装、签名及分发方案。
- 未检测到组件时，程序使用豆包工具栏兼容模式。目前只适配默认位置安装的豆包输入法 **1.0.0.23**，需要开启悬浮工具栏。
- 普通软件模拟 Alt 不等同于可用的语音触发。不能把“虚拟麦克风已安装”或“检查通过”当作豆包一定能输入的证明。

因此，当前 Windows 版本更适合开发和受控环境试用。具体依据见 [Windows 输入兼容性](windows-input-findings.md)和 [UMDF 发布缺口](../research/windows-umdf/VALIDATION.md#正式交付前的剩余工作)。

### macOS

- 系统基线：macOS 14.2+；已验证 Apple Silicon，Intel 尚未实机验证。
- 打开构建出的 DMG，运行「安装豆包远程」。缺少 BlackHole 2ch 时，安装器从官方来源获取并校验，再通过系统管理员认证安装；已有设备会复用。
- 按安装器提示处理重启。在豆包和本程序中均选择 **BlackHole 2ch**。
- 在「系统设置 → 隐私与安全性 → 辅助功能」允许主应用，以及应用包内的输入代理：

  ```text
  /Applications/DoubaoRemote.app
  /Applications/DoubaoRemote.app/Contents/Resources/DoubaoRemoteInput.app
  ```

- 默认快捷键为 **Fn / 地球仪**。切换到豆包输入法，或在豆包中启用全局语音；把豆包的长按快捷键与程序设置保持一致。

现有 Mac 产物使用开发签名，尚未完成 Developer ID 公证。正式发行条件与具体实测范围见 [macOS 验证记录](macos-validation.md)。

## 检查配置

从托盘或菜单栏打开「配置页」，核对：

1. **运行环境**：查看虚拟麦克风、豆包安装及运行、豆包麦克风、长按键和语音开关的结果。Mac 还会检查当前输入法及辅助功能权限。
2. **音频与网络**：选择对应虚拟设备，以及手机能够访问的电脑局域网 IP。默认优先以太网；电脑和手机不必都用 Wi-Fi。
3. **保存设置**：IP 或端口变化后退出、重开程序，再重新扫码。

「重新检测」检查已保存的配置，不会覆盖表单中尚未保存的输入。黄色“无法确认”表示字段、权限或设备状态不足以得出结论；请按结果说明核对，不能视为通过。

默认启用登录自启动，可在配置页关闭。

## 配对 iPhone

### 使用豆包远程 App

1. 按 [iOS 构建与安装说明](../ios/README.md)把 App 安装到 iPhone；当前没有 App Store 或 TestFlight 安装入口。
2. 电脑配置页点击「生成配对二维码」。
3. 打开「豆包远程」并扫码，配对成功后电脑二维码自动收起。

App 使用二维码内的证书建立本台电脑的专用信任，不需要安装系统证书。顶部“已配对”表示凭据已保存；实际声音连接在按住时自动建立。

### 使用 Safari 网页

用手机相机扫描**同一个二维码**进入向导，然后：

1. 用 Safari 下载并安装本机证书描述文件。
2. 在「设置 → 通用 → 关于本机 → 证书信任设置」开启配对向导所列本机 CA 的完全信任。
3. 返回向导，打开 HTTPS 输入页完成配对。

安装描述文件与开启信任是两个步骤，缺一不可。二维码五分钟内单次有效，流程中若过期，请在电脑重新生成。选择 App 时无需执行这组证书步骤。

## 开始说话

电脑光标放在目标输入框：

iPhone App、Android App 和网页都在顶栏以下任意位置按住说话，按下位置出现直径 180 的固定圆。圆内松手会在听写结束后延迟按 Enter；任意方向滑出圆外松手只完成听写。滑入顶栏后松手也只完成听写。

滑回操作区域后松手可恢复 Enter。回车默认等待 1000ms，可设为 0–5000ms；具体发送消息还是换行由当前电脑应用决定。等待期间再次按住、断线或暂停接收会取消待发回车；前台目标变化或修饰键仍按住时也会跳过。

首次使用请允许麦克风及局域网访问，若已松手或被权限窗口中断，完成授权后重新按住。正常松手传完尾音后关闭麦克风，连接和心跳保留；再次按住自动启动麦克风。App 前台保持亮屏，网页请求浏览器 Wake Lock；浏览器不支持或系统拒绝时，请手动保持亮屏。切后台、锁屏、来电或网络中断会结束本次输入。

## 连接与权限问题

- 电脑可接网线，手机使用同一路由器下可互相访问的 Wi-Fi；访客隔离、VPN 或虚拟网卡可能影响地址选择。
- macOS 若提示接收入站连接，允许本应用；Windows 只需为本程序放行所用私人网络。
- 默认手机端口为 TCP `38441`（首次向导）和 `38443`（HTTPS/WSS）。管理页的 `127.0.0.1:38440` 只在电脑本机使用，不能发给手机。
- 不需要开启虚拟设备的“侦听”，也不需要把声音播放到扬声器。

仍有问题时查看[故障排查](troubleshooting.md)。
