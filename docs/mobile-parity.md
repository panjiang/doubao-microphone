# 手机端交互基准

豆包麦克风 0.1.0 的 iPhone App、Android App 和手机网页对齐下列行为。两端原生 App 的首版构建号为 1。

| 项目 | 三端共同约定 |
| --- | --- |
| 顶栏 | 豆包麦克风、未配对／已配对、重新配对入口；整条顶栏不录音 |
| 按住区域 | 顶栏分割线以下，跟踪第一根手指；忽略额外手指 |
| 操作圆 | 原始触点居中，直径 180（iOS pt、Android dp、网页 CSS px）；固定位置、固定命中边界 |
| 圆样式 | `#234bc6`，填充不透明度 0.8、内描边 3；白色麦克风不透明度 0.8；滑出不变浅 |
| 结束动作 | 圆内松手延迟 Enter；任意方向滑出仅完成；滑回恢复 Enter；顶栏内松手仅完成 |
| 音量反馈 | 固定圆外扩散波纹，线宽 4；正常半径 90→180、周期 1.2 秒，三层间隔 0.4 秒；静音单层 90→112，1.6 秒加 0.4 秒停顿 |
| 提示 | 中央蓝色麦克风及“按住任意位置说话”；录音时显示两行回车说明，无列表圆点 |
| 过渡 | 圆、待命提示、回车说明均为 0.3 秒；异常立即清除操作圆；遵循系统减少动态效果设置 |
| 短按 | 150ms 后才初始化采音；电脑 ready 前松手取消，不回车 |
| 待命 | 尾帧先于 end，随后停止麦克风及音频处理；保留已建立的连接和 250ms 心跳 |
| 再次按住 | 重启麦克风，复用有效连接；取消上次待发 Enter；上一轮排空时等待，不叠加会话 |
| 中断 | 离开前台、失焦、音频中断或断线时取消并释放；返回后等待再次按住，不自动恢复录音 |
| 超时 | WSS 握手 5 秒、心跳失联 1 秒、结束确认 1.5 秒；错误有文字提示 |

两行说明分别为“圆内松手，会自动按 Enter 键。”和“圈外松手，不触发任何按键。”，使用灰色回车及斜线回车图形，不加 emoji 或圆点。电脑端仍负责延迟 Enter、焦点及修饰键检查，客户端不声明已读取识别结果。

## 平台适配

- 原生 App 内扫码，并在 App 内信任对应电脑 CA；网页通过手机相机扫码打开 HTTPS，首次仍需安装并信任电脑证书。网页重新配对入口会说明用手机相机重扫。
- App 前台常亮。网页请求 Screen Wake Lock；浏览器未提供此能力或系统拒绝时，无法保证常亮，需手动保持亮屏。
- 音频采样率遵循各平台采集接口：iOS 转换为 24kHz，Android／网页协商实际采样率，电脑统一重采样。三端使用同一 PCM16 协议和桌面会话控制。
- iOS 使用系统 SF Symbols，Android／网页使用对应的矢量图形；逻辑尺寸相同，系统字体和图标细节不要求逐像素一致。

## 用户实测

分别确认按住立即开口、首尾字、快速短按、圆内回车、向四周移出及滑回、滑入顶栏、等待回车时再次按住、断网及后台取消。松手后确认系统麦克风指示消失，待命不继续运行音频动画。网页需安装包含新版网页的电脑程序后刷新，单独更新 App 不会替换电脑内嵌网页。

本次仅构建及静态检查，不自动录音、触发按键或运行测试；功能通过需分别由用户实测确认。

## 深灰主题

iPhone、Android 与手机网页统一使用 `#161823` 深灰背景、浅色标题和灰白状态文字，配对标签使用白色 10% 不透明度背景；待命提示改为清晰的灰白文字，麦克风仍为品牌蓝。蓝色操作圆、波纹、命中范围和所有交互保持原设计。电脑管理页保持原有配色。
