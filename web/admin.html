豆包麦克风 · 电脑设置加载中

手机说话，电脑输入。

配置一次，日常只需按住手机上的按钮。

模拟模式：仅验证通信和状态，不产生原生音频或按键。

1 · 检查电脑

    检查已保存的配置，实际语音输入仍需实测。修改设置后，请保存并重新检测。

    Windows 安装包会自动准备虚拟麦克风。安装完成后在豆包中选择 CABLE Output；如果安装向导提示重启，请先重启。macOS 仍需安装 BlackHole 2ch。

    VB-CABLE 官方来源 / 支持项目macOS：BlackHole 2ch

    2 · 输入设置

    高级诊断

    Windows 豆包选择 CABLE Output，程序输出到 CABLE Input。macOS 两边均选择 BlackHole 2ch。修改后请保存并重新检测。

    Codex 空框兼容仅用于 Windows 的豆包兼容模式：当光标在 Codex 的空白编辑器时先写入一个普通空格，再启动语音。已有文字时不补空格，可随时关闭。

    测试会启动语音并在 3 秒后结束。点击后切换到测试输入框，观察豆包是否启动和结束。

    3 · 手机配对

    用“豆包麦克风”App 或手机相机扫描同一个二维码。App 可直接配对；手机相机扫码进入网页。二维码有效期 5 分钟。

    运行状态

    听写中锁定配置。暂停或撤销设备会结束当前会话。软件不读取豆包识别结果。开启故障录音诊断后，按住期间录制手机声音和虚拟麦克风回读，每份最多 30 秒，保留最近 3 次正常和 3 次故障样本；保存在本机数据目录的 diagnostics 文件夹，不上传。关闭后停止采集，已有样本可手动删除。
