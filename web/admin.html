语音遥控 · 本机配置加载中

手机说话，电脑输入。

配置一次，日常只需按住手机上的按钮。

模拟模式：仅验证通信和状态，不产生原生音频或按键。

1 · 检查电脑

先安装虚拟音频设备，然后在豆包中选择对应麦克风。只选择录音端，不要开启“侦听此设备”。

Windows：VB-CABLE 官方安装macOS：BlackHole 2ch 官方安装

2 · 输入设置

Windows 豆包选择 CABLE Output，程序输出到 CABLE Input。豆包兼容模式通过悬浮工具栏启动和结束语音，请在豆包中启用展示工具栏；当前仅适配默认位置安装的 Windows 版 1.0.0.23。macOS 两边均选择 BlackHole 2ch，Fn 仍需实测。

Codex 空框兼容仅用于 Windows 的豆包兼容模式：当光标在 Codex 的空白编辑器时先写入一个普通空格，再启动语音。已有文字时不补空格，可随时关闭。

测试会启动语音并在 3 秒后结束。点击后切换到测试输入框，观察豆包是否启动和结束。

3 · 手机配对

首次扫码后按向导安装本机证书，在 iPhone「关于本机 → 证书信任设置」开启信任，再打开输入页请求配对。

运行状态

听写中锁定配置。暂停或撤销设备会结束当前会话。软件不读取豆包识别结果。开启故障录音诊断后，按住期间录制手机声音和虚拟麦克风回读，每份最多 30 秒，保留最近 3 次正常和 3 次故障样本；保存在本机数据目录的 diagnostics 文件夹，不上传。关闭后停止采集，已有样本可手动删除。
